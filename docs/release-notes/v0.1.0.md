NimbusOS 0.1.0 is the first release: Debian 13 "Trixie" with KDE Plasma 6 and the Nimbus Control Center.

The Nimbus Control Center:
- Dashboard: live CPU, memory, network and storage, what the desktop, each Docker app and each virtual machine use, and what needs your attention, with a button to fix it.
- Apps: ten Docker apps in one click (Portainer, Uptime Kuma, Vaultwarden, Nextcloud All-in-One, Jellyfin, Pi-hole, Syncthing, Home Assistant, Grafana, Nginx Proxy Manager), or installed with your own ports, folders and settings.
- Virtual machines: Linux and Windows virtual machines with UEFI, Secure Boot and TPM, and their screens in the window.
- Storage & Shares: format disks, combine them into a pool with optional parity, and share folders with Windows, macOS and Linux. The Set up NAS wizard does it all in one go.
- Updates: Debian's security updates every day; NimbusOS updates from the signed NimbusOS repository, Automatic, Notify only or Off, on the Stable or Beta channel.

Install it from the live session with Install NimbusOS. You need a 64-bit PC with at least 4 GB of memory and 32 GB of disk.
